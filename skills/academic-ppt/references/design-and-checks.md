# 版式、字体与图表

新建PPT默认16:9，采用简洁的平面排版和一致边距。用户本次指定画幅、现有文件或模板时按其要求处理；页数依本次任务确定。

## 可复用布局

| 布局 | 适用内容 | 排版要点 |
| --- | --- | --- |
| 简洁封面 | 项目名称与汇报主题 | 大标题、简短汇报信息，保留留白 |
| 左文右图 | 背景意义与对象介绍 | 文字说明作用，图片占足够空间，不加卡片外框 |
| 整页方法图 | 关键规则与必要曲线 | 放大图件，变量解释与简短结论清楚分开 |
| 并排对比 | 方法、条件或局部结果 | 图件使用一致比例和对应标签，避免不公平的裁剪 |
| 原生表格 | 方法或对照条件 | 几个必要列，文字短，不把参数表做成密集页面 |
| 图表加结论 | 统计结果与意义 | 大图、少量关键指标，结论与证据放在同页 |

默认标题靠上、内容区充分留白、页码靠右下。避免把图注挤到页码上，图例和坐标轴标签占据足够空间。左右边距可参考画布宽度的5%，具体位置按内容和真实渲染调整。

## 字体和最小字号

中文字体为Microsoft YaHei（微软雅黑）；Latin字母、数字及数学用希腊字母为Times New Roman。根据文本片段设置字体，不能只给整个文本框设置微软雅黑后就认为数字已是新罗马。

在Office中核对实际字体映射及局部格式；原生图表检查西文字体和东亚字体，例如OOXML中的`a:latin`与`a:ea`。主题设置不会覆盖所有已有文本与图表属性，导入后仍需核对。

真正的字号单位为磅（pt）。所有页面可见文字至少18pt。CSS像素作者工具中按96dpi换算，24px对应18pt；OOXML字号通常以1/100磅计，1800对应18pt。不要把18px误认为18pt。

封面标题约44pt、页标题约32pt、正文21～24pt、辅助文字18～20pt为默认建议。页面信息过多时优先删重复、减少次要参数、放大或调整图表；允许改变页数时拆页。不能靠自动缩小文本或缩到18pt以下解决溢出。

图片中的文字按最终显示尺寸判断。图件中的图例、刻度、标签等汇报文字也应满足指定字体；新绘与替换的标注使用微软雅黑与Times New Roman混排，不只检查外围文本框。原图文字不能准确改造时明确未满足的部分，不能默默称为字体已统一。

如果裁剪图原字已太小，先记录完整标签与对应数据的关系，再裁去不影响证据的原字并用原生大字逐项补回，或依据源数据重绘；不可将截图放入页面后忽略其小字。不要删掉必要单位、组别、图例或坐标标签。实景照片作为证据保留，不为改变字体篡改实际场景；必要时用准确的大字标注解释。

正文变量与公式符号保持数学规范，需要索引时使用真正上下标，不用下划线代替。公式与索引也要检查实际显示大小；索引过小时放大公式或基准文字，保持18pt的可见文字下限，不能把整条小公式以极小图像塞入页面。

## 统一配色

| 用途 | 默认色 |
| --- | --- |
| 页面背景 | 白色 `#FFFFFF` |
| 标题和普通文字 | 深灰 `#202830` |
| 基线和次要信息 | 灰色 `#777E86` |
| 新方法或有依据的重点 | 蓝色 `#285C7E` |
| 必要的图表网格 | 浅灰 `#DCE0E4` |

颜色承担实际区别，跨页同一对象尽量同色。只为美观而随机给段落、数字或术语换色会破坏统一。科学图原有颜色若表达真实数据含义则保留，并明确图例，不机械改成黑白。

检查图表默认主题是否偷偷给标记添加橙色、绿色边框，必要时将标记填充、边线与对应系列统一。基线可搭配虚线、新方法搭配实线，帮助黑白阅读；不是每种研究都必须使用两组对照。

## 原生对象与数据

使用可编辑文本、表格和数据图表，尽可能保留工作簿和数据的编辑能力。科学示意图、照片和实际网络图保留真实证据，不能用装饰图替代。需要明确的可编辑流程图时按用户要求及演示文稿工具规范制作。

图表标签不小于18pt，减少不必要刻度，使用足够区分数据的精度。离散统计点默认直线连接，除非分析本身定义了平滑或拟合，不能用软件默认平滑曲线暗示未经计算的趋势。

没有有效数据的区间保留空缺，不填零或假点。误差棒取真实区间数据，不能仅凭均值随意添加。每次换项目更新图表数据、嵌入工作簿、单位、轴范围、标签及备注，避免旧项目信息残留。

## 最终检查

导出后在实际演示文稿应用或可用渲染工具中查看每一页。确认画幅、标题、图注、图例、字体、数据标签、页码和整体信息顺序；检查重叠、截断、缺字、图片比例及所有图中文字。XML检查能帮助发现问题，但不能证明画面可读。

检查原生图表和表格仍可编辑，数据和显示值一致，图表实际连线、标记及误差棒正确。只在确实打开并检查PowerPoint后才能声称已在PowerPoint检查。

材料确实不足时不编造图件或数据。完成有依据的内容并明确缺失部分；不得用历史项目结果填新课题，也不得把未验证的格式或编辑能力称为完成。
