# Word字体、变量与MathType公式

在生成、修改Word文档或说明其格式实施时读取。交付文档时，排版落实到文档对象，不仅在回复里口头承诺。

## 默认字体与保留原格式

| 对象 | 默认要求 |
| --- | --- |
| 中文标题、章节标题 | 黑体（SimHei） |
| 中文正文 | 宋体（SimSun），小四即12磅 |
| 表格内容及表头 | 五号即10.5磅；中文宋体（SimSun），字母、数字及数学用希腊字母Times New Roman |
| 字母、数字、数学用希腊字母（包括β） | Times New Roman |
| 正文数学变量 | Times New Roman，斜体 |
| 变量索引及幂次 | 真实下标或上标，按其语义设置斜体或正体 |
| 单独成行的公式 | 真正可编辑的MathType公式对象 |
| 正文内短公式、变量 | 普通可编辑文字 |

标题字号、层级、行距、页边距、图表和编号按本次要求或模板确定，不擅自加入装饰、颜色或特殊段落标记。正文12磅不意味着真实上下标必须取消正常缩放。

用户要求“格式不要动”时，保留现有标题层级、段落设置、编号、表格结构、图片位置和公式对象；只修改被授权的内容。默认字体不能覆盖明确要求保留的格式，用户另行指定的字体和变量修正则属于本次修改范围。

## 混合文字字体

为中文与西文设置实际字体。DOCX中，正文东亚字体设置为宋体，标题东亚字体设置为黑体；Latin与数字的`ascii`、`hAnsi`设置为Times New Roman。必要时拆分文字片段，为β等符号明确指定Times New Roman，避免因字符分类落入宋体。

不要把整段都设为Times New Roman而破坏中文字体，也不要只修改样式名称却保留覆盖样式的局部字体。检查正文、标题、表格、图注及页眉页脚中的可编辑文字。用户提供的图像内文字不因字体要求自动重画；若需重绘图表，依据真实源数据另行处理。

小四对应12磅，在WordprocessingML中`w:sz`通常为24（半磅单位）；表格内容及表头的五号对应10.5磅，`w:sz`为21。表格内容和表头均需落实实际字号，不能因继承正文或标题样式而变为12磅或其他字号。实际字号可由样式继承，检查继承结果而非只找显式属性。

## 正文变量及上下标

先根据公式定义和上下文识别数学变量。只给代表数学量的变量设置斜体，不将所有英文单词、模型名称、数字、单位、运算符或函数名一起改为斜体。

例如变量β应是Times New Roman斜体；变量下标为另一个数学索引时通常斜体，描述性下标如term、max通常正体。有明确领域规范或用户要求时遵循该规范。

对已确认变量设置真实上下标：Word对象使用Subscript或Superscript；DOCX中使用`w:vertAlign`的`subscript`或`superscript`。不得靠缩小字号、下移字符、保留下划线或贴近字母模拟下标。

不能全局替换所有下划线或数字，否则会损坏文件名、代码、缩写和普通文字。下标的字符范围由变量定义确定，不靠外观猜测。全文同一变量保持一致，必要时先建立简短变量表用于核对。

## 独立公式使用MathType

先检查已有公式对象并保留可编辑内容。新建或转换公式时，确认本机可用的MathType、Word或受支持的MathType接口，使用真实公式对象保存结果，不硬编码某台电脑的安装路径。

独立公式中的变量使用Times New Roman斜体，数字、函数名称及描述性文字按数学规范正体；式内中文用宋体。使用MathType样式设置和导出后的对象验证，不能依赖外围Word字体改变公式内部字形。

MathType对象、公式图片、Word原生公式和LaTeX源串是不同交付形式。Word原生公式（OMML）可以作为明确标记的转换中间文件，但不能在未转换完成时称为MathType定稿。不通过只改对象标签或ProgID来伪装格式。

在DOCX中核实真正的OLE对象、有效嵌入载荷、关系及预览。常见MathType标识为`Equation.DSMT4`，但有这个字符串并不足以证明有效。条件允许时在独立Word会话中打开副本，确认对象能进入MathType编辑，式子内容和预览正确，关闭自己创建的会话。

转换前后逐式核对符号、分数、上下标、正负号、括号、编号和正文引用。只把独立公式转换为MathType，正文短公式和变量继续作为文字保留。

如果环境缺少MathType能力，先检查是否能保留或复用现有有效对象，并完成文字和格式工作。确实不能创建或转换时，明确具体哪些独立公式仍未满足要求，保存清楚标记的中间稿，不擅自用图片或OMML当作已完成结果。

## 可观察的交付检查

检查实际字体与字号，正文为12磅，表格内容及表头均为10.5磅；同时检查β字体、变量斜体、真实上下标、公式数量和可编辑性。变量识别与公式语义需人工对照，不能只凭脚本通过断言。

用可用的文档工具打开或渲染全部页面，修复公式裁切、对象错位、断行、图注脱离与编号错误。文档制作技能可用时配合其验证流程；不可用时采用现有Word或文档渲染工具，不依赖本项目特定路径。

检查拼写波浪线时区分界面校对标记与实际字符格式。不要通过删除文字、给文字设白色或更改用户全局Word设置来掩盖问题；只有本次任务明确要求时才处理相应文档校对设置。
